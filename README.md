# 🛒 Dashboard Gerencial Olist

Dashboard desenvolvido em Power BI para análise gerencial de vendas utilizando dados públicos de e-commerce da Olist.

O projeto foi construído com foco em indicadores executivos, análise comercial e acompanhamento de performance de vendas.

# 🎯 Objetivo do Projeto

Criar um painel executivo para acompanhamento de:

- 💰 faturamento
- 📦 volume de pedidos
- 📈 ticket médio
- 👥 performance de vendedores
- 🏙️ desempenho regional
- 🛒 produtos mais vendidos
- ❌ cancelamentos

O dashboard foi estruturado para permitir análises estratégicas através de filtros dinâmicos e múltiplas visões gerenciais.
